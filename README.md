# penningtonj.com

Founder page for Justin Pennington, founder of Infraxio (Ponte Vedra, Florida).

Next.js (App Router) + Tailwind, deployed on Vercel (infraxio team). Pushing `main` deploys.

```bash
npm run dev
```

Content lives in `lib/site.ts` and `app/page.tsx`. Content rules: location is Ponte Vedra, Florida; no prior companies, employers, or legal-case references anywhere (copy, metadata, schema, alt text, comments).
